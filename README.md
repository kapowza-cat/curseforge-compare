2 tools that are useful for mc servers

compare: Input 2 paths, compares the mods in each. Press enter to the 'again' prompt to recalculate the comparison, useful to see if your changes worked (run script again if you want to change the paths). If a mod changed its name in an update, it will likely show duplicates.

ai generated

standby: Sets laptop lid close settings to 'do nothing'. Confirm the prompt and settings are reverted to 'sleep'. Useful to leave the lid closed and still have a server running. Requires admin.
