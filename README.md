2 tools that are useful for mc servers

compare: input 2 paths, compares the mods in each. press enter to the 'again' prompt to recalculate the comparison, useful to see if your changes worked. if a mod changed its name in an update, it will likely show duplicates.
ai generated

standby: sets laptop lid close settings to 'do nothing'. confirm the prompt and settings are reverted to 'sleep' useful to leave the lid closed and still have a server running. requires admin
